# PurffleShorts Studio legal pages

This folder contains a small static website for GitHub Pages:
- `index.html`
- `terms.html`
- `privacy.html`

## Before publishing
1. Replace `[REPLACE WITH YOUR SUPPORT EMAIL]` in all pages with an email address you monitor.
2. Review the Privacy Policy carefully. In particular, complete section 4 with the real storage/hosting details: where OAuth tokens, videos, logs and settings are stored, and whether a remote relay/server receives them.
3. Do not submit the URLs to TikTok until the pages are public and accurate.

## GitHub Pages setup
1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload all three HTML files to the repository root (and optionally this README).
3. In repository Settings → Pages, set deployment source to Deploy from a branch, branch `main`, folder `/(root)`, then Save.
4. After GitHub Pages is published, the URLs will be:
   - `https://YOUR-GITHUB-USERNAME.github.io/terms.html`
   - `https://YOUR-GITHUB-USERNAME.github.io/privacy.html`

Replace `YOUR-GITHUB-USERNAME` with your exact GitHub username.
